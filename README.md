# ChewPlay 🍽️▶️

Android-приложение: видео играет на весь экран, пока человек **жуёт**, и ставится на паузу, когда он **перестал жевать**. Как только жевание возвращается — видео продолжается с того же места.

Задумано как «мотиватор» для детей (и не только): мультик идёт, пока жуёшь.

---

## Как это работает

```
CameraX (фронтальная камера, 640×480)
        │  кадры RGBA
        ▼
ML Kit Face Detection (контуры губ, офлайн, модель внутри APK)
        │  раствор рта / ширина лица  +  ширина рта / ширина лица
        ▼
ChewingSignal: сглаживание → вычитание медленного дрейфа → поиск «зубцов» (пиков)
        │  «жуёт прямо сейчас» (пик был меньше 1.4 с назад)
        ▼
EatingStateMachine: гистерезис (пауза через 2.5 с тишины, запуск через 0.45 с жевания)
        │
        ▼
ExoPlayer: play() / pause() — позиция воспроизведения сохраняется
```

Ключевая идея: жевание — это **ритмичные колебания** раствора рта с частотой примерно 0,8–2 Гц. Все расстояния делятся на ширину лица, поэтому сигнал не зависит от расстояния до камеры. Медленные изменения (наклон головы, мимика) убираются вычитанием среднего по окну 2.6 с, а порог «зубца» настраивается под конкретное лицо калибровкой.

## Возможности

- 🎬 Видео на весь экран без элементов управления, зациклено (ExoPlayer / Media3).
- ⏸️ Автоматическая пауза, когда жевание прекращается; продолжение — с того же места.
- ⏱️ Плавность: настраиваемые задержки паузы/запуска, чтобы видео не дёргалось на каждом кадре.
- 🎚️ Чувствительность + калибровка по шуму (мимика, дыхание) — убирает ложные срабатывания.
- 📈 Отладочный график сигнала: видно зубцы жевания и текущий порог.
- 📷 Переключение фронтальная/основная камера, маленькое превью камеры.
- 🔒 Всё считается на телефоне, интернет не нужен, видео никуда не отправляется.
- 🧩 Экран настроек: выбор видео, задержки, камера, калибровка, сброс.

## Требования

- Телефон на Android **6.0 (API 23)** и выше, с камерой.
- Для сборки: JDK 17 + Android SDK 34 (Android Studio Koala или новее), либо GitHub Actions (см. ниже).

## Сборка APK

### Вариант A — GitHub Actions (ничего устанавливать не нужно)

Самый простой путь, если не хочется ставить Android Studio.

1. Заведите пустой репозиторий на GitHub.
2. Загрузите туда **содержимое папки `ChewPlay`** (важно: `.github`, `app`, `build.gradle.kts` должны лежать в корне репозитория).
3. Откройте вкладку **Actions** → workflow **Build debug APK** → **Run workflow**.
4. Через 3–5 минут зайдите в завершившийся запуск и скачайте артефакт **chewplay-debug-apk**.
5. Внутри zip — файл `app-debug.apk`. Это и есть приложение.

Файл `.github/workflows/build-apk.yml` уже в проекте, менять ничего не нужно.

### Вариант B — Android Studio

1. Установите [Android Studio](https://developer.android.com/studio) (в нём уже есть JDK 17 и Android SDK).
2. **File → Open** → выберите папку `ChewPlay`.
3. Дождитесь Gradle Sync. Если Studio предложит создать Gradle wrapper — согласитесь (кнопка «OK»/«Create»).
4. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
5. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант C — командная строка

Нужны JDK 17 и Android SDK (переменная `ANDROID_HOME`).

```bash
cd ChewPlay
gradle wrapper --gradle-version 8.7   # один раз, если нет gradlew
./gradlew :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.

Проверить логику детектора без телефона:

```bash
./gradlew :app:testDebugUnitTest
```

### Установка на телефон

1. Перекиньте `app-debug.apk` на телефон (кабель, облако, Telegram «себе»).
2. Откройте файл. Android спросит про установку из неизвестного источника — разрешите для файлового менеджера/Telegram.
3. Поставьте приложение, при первом запуске разрешите **камеру**.

APK собран debug-ключом — для личного пользования этого достаточно. Для Play Store нужен release-keystore и подпись.

## Первый запуск

1. Разрешите доступ к камере (без неё контроль не работает — видео будет играть без пауз).
2. Нажмите **«Выбрать видео»** и выберите файл из памяти.
3. Поставьте телефон на подставку так, чтобы **лицо было в кадре фронтальной камеры**, на расстоянии примерно **30–50 см** (ML Kit точнее считает контуры, когда лицо крупное).
4. Начните жевать — видео пойдёт. Перестаньте — через ~3–4 секунды встанет на паузу.
5. Шестерёнка в правом нижнем углу — настройки.

## Настройка точности

Порядок действий, если работает не так, как хочется:

1. Включите в настройках **«Отладочный график»**.
2. Посмотрите на график: при жевании должны быть видны **ритмичные зубцы**, а счётчик «пики» — расти до 2–4.
3. Если зубцов нет или они слабые — поднимите **чувствительность**, поднесите телефон ближе, включите свет.
4. Если видео «дёргается», когда человек просто говорит или улыбается:
   - нажмите **«Калибровать»** и 3 секунды посидите спокойно, не жуя;
   - либо опустите чувствительность.
5. **«Пауза после остановки»** — сколько ждать тишины перед паузой (1–6 с).
6. **«Задержка возобновления»** — сколько нужно жевать, чтобы видео пошло (0–1.5 с).

### Если видео не запускается

- Человек не в кадре / лицо слишком маленькое / темно → плашка покажет «Не вижу лицо».
- Слишком низкая чувствительность или завышенный порог после калибровки → сбросьте настройки.
- Отключён тумблер **«Следить за жеванием»** → видео играет всегда.

## Ограничения и честные предупреждения

- **Разговор, смех, зевота** могут приниматься за жевание. Это лечится калибровкой и чувствительностью, но не идеально.
- **Жевание с закрытым ртом** ловится хуже (сигнал слабее) — держите телефон ближе и включите чувствительность повыше.
- **Поворот головы** больше ~45° — сигнал ненадёжен; считается, что человек не ест.
- **Батарея и нагрев**: непрерывная камера + ML-инференс заметно расходуют заряд. Для долгого использования лучше держать телефон на зарядке.
- **Экран не гаснет** (флаг `KEEP_SCREEN_ON`), пока приложение на переднем плане.
- Если приложение ушло в фон, камера освобождается, видео ставится на паузу.
- **Петля поведения**: видео стоит, пока не начнёшь жевать — это и есть задумка, но ребёнку нужно один раз начать есть, чтобы «разблокировать» мультик.

## Что можно улучшить дальше

- Определять именно **еду** (рука/вилка/еда у рта) — сейчас сигнал только по лицу.
- Поддержка **плейлиста** и нескольких видео.
- Запоминать «профиль» жевания для конкретного человека (свой порог).
- Foreground-service, чтобы контроль работал при выключенном экране.
- Release-сборка с подписью и minify.

## Приватность

Камера используется только для локального анализа кадров. Кадры не сохраняются и никуда не отправляются. Сеть приложению не нужна (модель ML Kit встроена в APK).
